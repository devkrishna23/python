# ♟ Python Chess Engine (Work in Progress)

A modular chess engine written in Python. This project focuses on clean architecture, correctness of move logic, and will later include a classical AI opponent using **Minimax with alpha-beta pruning**.

---

## Features (Current)

- Modular board and piece classes
- Automatic initial board setup
- Unicode board rendering for terminal
- Utility functions for move handling
- Basic test scaffold (`test_chess.py`)

---

## Planned / In Progress

- Full legal move generation
- Check / checkmate detection
- Move history (PGN-style)
- AI opponent (Minimax)
- Difficulty levels via depth limits
- “Explain move” mode for AI debugging
